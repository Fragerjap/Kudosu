# Kudosu - Sudoku app

Standalone Sudoku with puzzles generator. 

## Play anywhere

Everything is stored on your device. You may save/load your data manually. 

### Track progress

Each puzzle is unique, as it is saved to your local account.

### Generator

```
Single solution
Only logic, no guessing
Four difficulties (harder tecnhiques)
```
